Пеш аз боргирӣ

Барнома ҳоло дар Google Play нест.

Android файли APK-еро, ки аз браузер ё мудири файл насб мешавад, «барнома аз манбаи ношинос» меномад. Ин огоҳӣ худ аз худ маънои вирус доштанро надорад — он танҳо мегӯяд, ки насб аз Google Play нест.

!
Иҷозатро танҳо барои як насб диҳед.

APK-ро фақат аз ҳамин саҳифаи расмӣ гиред. Ба Chrome, Samsung Internet ё Files иҷозат диҳед, барномаро насб кунед ва баъд иҷозати «Allow from this source»-ро боз хомӯш намоед. Google Play Protect-ро хомӯш накунед. Агар телефон на танҳо «манбаи ношинос», балки «барномаи зараровар» ё «App blocked» гӯяд, насбро қатъ кунед.

  1. 1
    APK-ро боргирӣ кунед

    Тугмаи сабзи поёнро пахш кунед ва файли Tajik-STT-Collector.apk-ро кушоед.

  2. 2
    Танзимотро кушоед

    Агар насб манъ шавад, дар ҳамон паём Settings / Танзимот-ро пахш кунед.

  3. 3
    Ба манбаи дуруст иҷозат диҳед

    Барномаеро интихоб кунед, ки APK-ро кушод: Chrome, Samsung Internet, Files ё My Files. Allow from this source-ро фаъол карда, ба насб баргардед.

  4. 4
    Баъд аз насб иҷозатро хомӯш кунед

    Ба ҳамон саҳифаи танзимот баргашта, иҷозати насб аз ин манбаъро хомӯш намоед.

Samsung Galaxy

Settings → Security and privacy → More security settings → Install unknown apps. Chrome ё My Files-ро интихоб кунед. Агар Auto Blocker монеъ шавад, онро танҳо барои вақти насб хомӯш карда, баъд аз насб дубора фаъол намоед.

Xiaomi, Redmi ё POCO

Одатан: Settings → Privacy protection → Special permissions → Install unknown apps. Дар баъзе версияҳо: Additional settings → Privacy → Special app access → Install unknown apps.

HONOR ё HUAWEI

Дар ҷустуҷӯи Settings нависед: Install unknown apps, Установка неизвестных приложений ё Внешние источники. Сипас браузер ё Files-ро интихоб кунед.

Дигар телефонҳои Android

Одатан: Settings → Apps → Special app access → Install unknown apps. Номи бахш вобаста ба версияи Android метавонад каме фарқ кунад.

Пеш аз боргирӣ

Оё иштирок ҳатмист?

Не. Иштирок пурра ихтиёрӣ аст. Шумо метавонед сабтро пеш аз фиристодан пок кунед ё минбаъд иштирок накунед.

Сабтҳо дар куҷо нигоҳ дошта мешаванд?

Дар MVP сабтҳои қабулшуда дар компютери лоиҳа нигоҳ дошта мешаванд. Сабти ҳанӯз нафиристодашуда муваққатан дар хотираи хусусии барнома мемонад; пас аз тасдиқи қабули сервер нусхаи навбатӣ аз телефон пок мешавад.

Чаро телефон насби APK-ро мепурсад?

Барнома ҳоло дар Google Play нест. Android браузер ё мудири файлро «манбаи ношинос» мешуморад. APK-ро танҳо аз ҳамин саҳифа гиред, иҷозатро ба барномаи дуруст танҳо барои насб диҳед ва баъд онро хомӯш кунед. Дастури пурраи насб.

Оё танҳо зеркашӣ розигӣ ба сабти овоз аст?

Не. Боргирӣ ва истифода қабули шартҳоро нишон медиҳад, аммо барои сабт ва истифодаи овоз дар дохили барнома розигии равшан ва алоҳида талаб мешавад.
