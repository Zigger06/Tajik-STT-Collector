Муносибати равшан ба маълумот

Сиёсати махфият

Ин санад мефаҳмонад, ки Tajik STT Collector ҳангоми сабт ва санҷиши нутқи тоҷикӣ кадом маълумотро мегирад, барои чӣ истифода мебарад ва чӣ гуна шумо онро идора карда метавонед.

Хулосаи кӯтоҳ: иштирок ихтиёрӣ аст; овоз танҳо пас аз розигии равшани шумо сабт мешавад; барнома реклама ё пайгирии маркетингӣ надорад; маълумот тавассути HTTPS ба компютери лоиҳа фиристода мешавад. Дар бахши «Маълумоти ман» шумо метавонед сабтҳои серверии худро бинед, гӯш кунед, боргирӣ кунед, ҳазф кунед ё розигии худро барои иштироки оянда бозпас гиред.

1. Доира ва масъули лоиҳа

Ин сиёсат ба барномаи Android-и Tajik STT Collector, сервери дар компютери лоиҳа ҷойгиршуда ва ҳамин вебсайт дахл дорад. Масъули амалии лоиҳа соҳиби репозитории Zigger06 мебошад.

Ҳадафи лоиҳа ҷамъоварии маводи босифати ихтиёрӣ барои таҳқиқ, таҳия ва санҷиши шинохти автоматии нутқи тоҷикӣ (Tajik‑STT) аст.

2. Кадом маълумот ҷамъ мешавад

Маълумоте, ки шумо пешниҳод мекунед

  • сабти овози шумо дар формати WAV;
  • ном ё рамзи интихобкардаи шумо — метавонед тахаллус истифода баред;
  • минтақа ва лаҳҷа, агар ворид кунед;
  • матни тоҷикие, ки шумо пешниҳод мекунед, ва манбаи он, агар ихтиёрӣ ворид кунед;
  • тасдиқ, рад, ислоҳ ва шарҳҳое, ки ҳангоми санҷиши матн ё аудио медиҳед;
  • розигии шумо ба истифодаи сабт барои Tajik‑STT ва ҳолати бозпас гирифтани он.

Маълумоти техникӣ

  • рамзи тасодуфии ихтиёрӣ (UUID), рамзи сабт ва рамзи матн;
  • давомнокӣ, суръати намунагирӣ, ҳеши файл, ҳолати санҷиш ва вақтҳои эҷод;
  • калиди махфии тасодуфии дастгоҳ барои тасдиқи дархостҳои худи шумо. Калиди аслӣ дар телефони шумо нигоҳ дошта мешавад; сервер танҳо salt ва ҳеши онро нигоҳ медорад;
  • суроғаи техникии сервер, ки барнома аз конфигуратсияи расмии лоиҳа худкор мегирад.

Ҳангоми пайвастшавӣ суроғаи IP ва маълумоти техникии дархост метавонанд аз ҷониби хизматрасониҳои шабака коркард шаванд. Сервери MVP онҳоро қасдан ҳамчун профили доимии корбар дар SQLite нигоҳ намедорад; IP метавонад муваққатан барои маҳдуд кардани сӯиистифода истифода шавад.

Маълумоте, ки барнома қасдан намегирад

Рақами телефон, почтаи электронӣ, рӯйхати тамосҳо, ҷойгиршавии дақиқ, аксҳо, рекламадиҳӣ ва таҳлили маркетингӣ талаб ё ҷамъ карда намешаванд.

3. Мақсади коркард ва розигӣ

Маълумот танҳо барои вазифаҳои зерин коркард мешавад:

  • сохтан, омӯзондан, арзёбӣ ва беҳтар кардани Tajik‑STT;
  • санҷиши дурустии матн ва мувофиқати аудио;
  • қабул, санҷиш ва омода кардани матнҳои пешниҳодкардаи ихтиёриён барои сабти минбаъда;
  • пешгирии такрор, муайян кардани сифати сабт ва ҳисоботи умумии лоиҳа;
  • ҳифзи техникии сервер, маҳдуд кардани сӯиистифода ва таҳқиқи хатогиҳо.

Коркарди овоз ба розигии ошкори шумо такя мекунад. Танҳо зеркашӣ кардани APK розигӣ ба сабти овоз нест: пеш аз сабт дар дохили барнома қуттии алоҳидаи розигӣ нишон дода мешавад.

4. Нигоҳдорӣ ва интиқоли маълумот

  • Сабти ҳанӯз нафиристодашуда муваққатан дар ҷузвдони хусусии барнома дар телефони шумо мемонад.
  • Пас аз тасдиқи қабули сервер, нусхаи навбатии WAV аз телефон пок мешавад; файли WAV дар ҷузвдони сервер ва метамаълумот дар SQLite-и компютери лоиҳа нигоҳ дошта мешаванд.
  • Интиқол аз интернет тавассути HTTPS ва Tailscale Funnel рамзгузорӣ мешавад.
  • GitHub Pages танҳо сайт ва пайванди APK-ро ҷойгир мекунад; сабтҳои овоз ба GitHub Pages фиристода намешаванд.
  • Ҷузвдонҳои дорои овози воқеӣ аз Git хориҷ карда шудаанд ва набояд ба репозитории ҷамъиятӣ бор карда шаванд.
  • Нусхаи эҳтиётии худкори Android барои маълумоти барнома хомӯш карда шудааст.
Муҳим барои MVP

Барнома суроғаи расмии https://…ts.net-ро худкор мегирад ва аз ихтиёрӣ парол ё калид намепурсад. Панели маъмурӣ ва калиди он танҳо дар компютери маъмур мемонанд; порти серверро мустақиман дар роутер боз накунед. Дар бораи Funnel.

5. Кӣ дастрасӣ дорад ва чӣ мубодила мешавад

Маъмури лоиҳа ба пойгоҳи додаҳо ва файлҳои аслӣ дастрасӣ дорад. Барои назорати сифат ихтиёриёни дигар метавонанд сабти ба онҳо барои санҷиш таъиншударо бо матни мувофиқ гӯш кунанд ё матни пешниҳодшуда ва манбаи ихтиёрии онро санҷанд; барнома ба онҳо номи интихобкардаи саҳмгузор ё ID-и ӯро нишон намедиҳад.

Маълумот барои реклама фурӯхта намешавад. Пеш аз нашри маҷмӯаи аудио ё додани сабтҳои аслӣ ба шахси сеюм огоҳии алоҳида, асоси ҳуқуқӣ ва ҳангоми зарурат розигии нав лозим мешавад. Моделҳои омӯхташуда, омори ҷамъбастӣ ва натиҷаҳои бе шахсияти мустақим метавонанд барои таҳқиқ ва рушди Tajik‑STT истифода шаванд.

6. Муҳлати нигоҳдорӣ, ҳазф ва бозпас гирифтани розигӣ

Сабтҳо то вақти зарур будан барои ҳадафи Tajik‑STT ё то ҳазфи онҳо аз ҷониби шумо/маъмур нигоҳ дошта мешаванд. Дар бахши «Маълумоти ман» метавонед ҳар як сабти серверии худро алоҳида ҳазф кунед ё ҳамаи сабтҳои худро якбора ҳазф намоед.

Ҳангоми ҳазфи сабт, файли WAV-и аслӣ аз нигоҳдории фаъоли сервер хориҷ мешавад, сабти он аз SQLite пок мегардад ва санҷишҳои аудиоии вобаста бо foreign key ҳазф мешаванд. Азбаски экспорт танҳо аз сабтҳои ҳозираи база сохта мешавад, сабти ҳазфшуда ба экспорт ва омӯзиши оянда дохил намешавад.

Ҳангоми «Ҳазфи ҳамаи сабтҳои ман» барнома инчунин сабтҳои ҳанӯз нафиристодаи навбати ҳамин телефонро пок мекунад. Ин амал матнҳои пешниҳодкардаи шумо ё таърихи санҷиши матнҳоро худкор ҳазф намекунад.

Агар розигии худро бозпас гиред, сервер иштироки навро манъ мекунад ва сабтҳои мавҷудаи шумо ба экспортҳои нави омӯзишӣ дохил намешаванд. Онҳо то вақте ки шумо онҳоро боргирӣ ё ҳазф кунед, барои идоракунии худи шумо нигоҳ дошта мешаванд.

Муҳим: ҳазф кардани WAV ё бозпас гирифтани розигӣ омӯзиши модели қаблан анҷомёфтаро худкор «барнамегардонад». Агар сабт пештар дар омӯзиши модели анҷомёфта истифода шуда бошад, таъсири он аз вазнҳои модели тайёр бо ҳазфи оддии файл ба таври худкор хориҷ намешавад.

7. Ҳуқуқҳои шумо

Бо назардошти қонунҳои татбиқшаванда, шумо метавонед:

  • дар бахши «Маълумоти ман» сабтҳои серверии худро ва ҳолати онҳоро бинед;
  • сабти худро гӯш кунед ва WAV-и онро боргирӣ намоед;
  • як сабт ё ҳамаи сабтҳои овозии худро ҳазф кунед;
  • розигии худро барои иштироки оянда бозпас гиред;
  • барои масъалаҳое, ки ҳоло дар барнома худкор идора намешаванд, ба лоиҳа муроҷиат кунед;
  • дар бораи истифодаи нодуруст ё ҳодисаи амниятӣ хабар диҳед.

Бозпас гирифтани розигӣ ба коркарде, ки пеш аз он анҷом шуда буд, худ аз худ таъсири бозгаштӣ намедиҳад.

8. Амният ва иштироки ноболиғон

Лоиҳа панели маъмурии маҳаллӣ, калиди алоҳидаи маъмур, HTTPS, anonymous device authentication, маҳдудкунии дархостҳо ва ҷудо кардани номи сабткунанда аз вазифаи санҷишро истифода мебарад. Донистани UUID-и ихтиёрӣ барои дастрасӣ ба бахши «Маълумоти ман» кофӣ нест: credential-и тасодуфии дастгоҳ низ лозим аст.

Бо вуҷуди ин, ҳеҷ низоми техникӣ амнияти мутлақро кафолат дода наметавонад.

Версияи MVP барои шахсони 18‑сола ва калонтар пешбинӣ шудааст. Сабти овози ноболиғ танҳо бо тартиби алоҳида ва розигии дурусти волидайн ё намояндаи қонунӣ иҷозат дода мешавад.

9. Маълумот дар бораи ҳамин вебсайт

Сайт cookie-и таблиғотӣ ё таҳлили дохилии маркетингӣ надорад. Он тавассути GitHub Pages пешниҳод мешавад; GitHub метавонад журналҳои техникии монанди IP, браузер ва вақти дархостро мувофиқи Сиёсати умумии махфияти GitHub коркард кунад.

10. Тамос ва тағйирот

Барои саволи махфият ё масъалае, ки аз бахши «Маълумоти ман» ҳал намешавад, дар GitHub-и лоиҳа дархости нав кушоед ва танҳо хоҳиши роҳи тамоси хусусиро нависед. Овоз, номи ҳақиқӣ, рақами телефон, credential-и дастгоҳ, рамзи ихтиёрӣ ё дигар маълумоти ҳассосро дар Issue-и ҷамъиятӣ нагузоред.

Ҳангоми тағйири намудҳои маълумот ё ҳадафи коркард ин сиёсат нав мешавад. Агар тағйирот барои розигии қаблӣ муҳим бошад, барнома бояд пеш аз сабти нав розигии шуморо дубора талаб кунад.
