Муносибати равшан ба маълумот

Сиёсати махфият

Ин санад мефаҳмонад, ки Tajik STT Collector ҳангоми сабт ва санҷиши нутқи тоҷикӣ кадом маълумотро мегирад, барои чӣ истифода мебарад ва чӣ гуна ҳифз мекунад.

Мундариҷа 1. Доира ва масъул 2. Маълумоти ҷамъшаванда 3. Мақсад ва розигӣ 4. Нигоҳдорӣ ва интиқол 5. Дастрасӣ ва мубодила 6. Муҳлат ва ҳазф 7. Ҳуқуқҳои шумо 8. Амният ва кӯдакон 9. Ин вебсайт 10. Тамос

Хулосаи кӯтоҳ: иштирок ихтиёрӣ аст; овоз танҳо пас аз розигии равшани шумо сабт мешавад; барнома реклама ё пайгирии маркетингӣ надорад; маълумоти MVP тавассути HTTPS фиристода шуда, дар телефони шумо ва компютери лоиҳа нигоҳ дошта мешавад.

1. Доира ва масъули лоиҳа

Ин сиёсат ба барномаи Android-и Tajik STT Collector, сервери дар компютери лоиҳа ҷойгиршуда ва ҳамин вебсайт дахл дорад. Масъули амалии лоиҳа соҳиби репозитории Zigger06 мебошад.

Ҳадафи лоиҳа ҷамъоварии маводи босифати ихтиёрӣ барои таҳқиқ, таҳия ва санҷиши шинохти автоматии нутқи тоҷикӣ (Tajik‑STT) аст.

2. Кадом маълумот ҷамъ мешавад

Маълумоте, ки шумо пешниҳод мекунед

  • сабти овози шумо дар формати WAV;
  • ном ё рамзи интихобкардаи шумо — метавонед тахаллус истифода баред;
  • минтақа ва лаҳҷа, агар ворид кунед;
  • тасдиқ, рад, ислоҳ ва шарҳҳое, ки ҳангоми санҷиши матн ё аудио медиҳед;
  • розигии шумо ба истифодаи сабт барои Tajik‑STT.

Маълумоти техникӣ

  • рамзи тасодуфии ихтиёрӣ (UUID), рамзи сабт ва рамзи матн;
  • давомнокӣ, суръати намунагирӣ, ҳеши файл, ҳолати санҷиш ва вақтҳои эҷод;
  • суроғаи сервер ва калиди лоиҳа, ки дар танзимоти хусусии барнома нигоҳ дошта мешаванд.

Ҳангоми пайвастшавӣ суроғаи IP ва маълумоти техникии дархост метавонанд аз ҷониби хизматрасониҳои шабака коркард шаванд. Сервери MVP онҳоро қасдан дар пойгоҳи додаҳои лоиҳа нигоҳ намедорад.

Маълумоте, ки барнома қасдан намегирад

Рақами телефон, почтаи электронӣ, рӯйхати тамосҳо, ҷойгиршавии дақиқ, аксҳо, рекламадиҳӣ ва таҳлили маркетингӣ талаб ё ҷамъ карда намешаванд.

3. Мақсади коркард ва розигӣ

Маълумот танҳо барои вазифаҳои зерин коркард мешавад:

  • сохтан, омӯзондан, арзёбӣ ва беҳтар кардани Tajik‑STT;
  • санҷиши дурустии матн ва мувофиқати аудио;
  • пешгирии такрор, муайян кардани сифати сабт ва ҳисоботи умумии лоиҳа;
  • ҳифзи техникии сервер ва таҳқиқи хатогиҳо.

Коркарди овоз ба розигии ошкори шумо такя мекунад. Танҳо зеркашӣ кардани APK розигӣ ба сабти овоз нест: пеш аз сабт дар дохили барнома қуттии алоҳидаи розигӣ нишон дода мешавад.

4. Нигоҳдорӣ ва интиқоли маълумот

  • Сабти ҳанӯз нафиристодашуда муваққатан дар ҷузвдони хусусии барнома дар телефони шумо мемонад.
  • Пас аз тасдиқи қабули сервер, нусхаи навбатии WAV аз телефон пок мешавад; файли WAV дар ҷузвдони сервер ва метамаълумот дар SQLite-и компютери лоиҳа нигоҳ дошта мешаванд.
  • Интиқол аз интернет тавассути HTTPS ва Tailscale Funnel рамзгузорӣ мешавад. Мувофиқи ҳуҷҷатҳои Tailscale, relay муҳтаворо рамзкушоӣ карда наметавонад ва суроғаи IP-и компютери серверро аз корбар пинҳон мекунад.
  • GitHub Pages танҳо сайт ва пайванди APK-ро ҷойгир мекунад; сабтҳои овоз ба GitHub Pages фиристода намешаванд.
  • Ҷузвдонҳои дорои овози воқеӣ аз Git хориҷ карда шудаанд ва набояд ба репозитории ҷамъиятӣ бор карда шаванд.
  • Нусхаи эҳтиётии худкори Android барои маълумоти барнома хомӯш карда шудааст.
Муҳим барои MVP

Барои кори онлайн танҳо суроғаи расмии https://…ts.net-ро истифода кунед. Панели маъмурӣ танҳо дар худи компютер дастрас аст. Калиди лоиҳаро ба шахси ношинос нафиристед ва порти серверро мустақиман дар роутер боз накунед. Дар бораи амнияти Funnel.

5. Кӣ дастрасӣ дорад ва чӣ мубодила мешавад

Маъмури лоиҳа ба пойгоҳи додаҳо ва файлҳои аслӣ дастрасӣ дорад. Барои назорати сифат ихтиёриёни дигар метавонанд сабти бе номро бо матни мувофиқ гӯш кунанд; барнома ба онҳо номи интихобкардаи сабткунанда ё ID-и ӯро нишон намедиҳад.

Маълумот барои реклама фурӯхта намешавад. Пеш аз нашри маҷмӯаи аудио ё додани сабтҳои аслӣ ба шахси сеюм огоҳии алоҳида, асоси ҳуқуқӣ ва ҳангоми зарурат розигии нав лозим мешавад. Моделҳои омӯхташуда, омори ҷамъбастӣ ва натиҷаҳои бе шахсияти мустақим метавонанд барои таҳқиқ ва рушди Tajik‑STT истифода шаванд.

6. Муҳлати нигоҳдорӣ ва ҳазф

Маълумот то вақти зарур будан барои ҳадафи Tajik‑STT ё то гирифтани дархости асосноки ҳазф нигоҳ дошта мешавад. Маъмур бояд нусхаҳои зиёдатӣ ва сабтҳои радшударо давра ба давра пок кунад.

Шумо метавонед ҳазфи сабтҳои аслӣ ва маълумоти вобастаро дархост кунед. Барои ёфтани сабтҳо рамзи ихтиёрии дохили барнома лозим шуда метавонад. Таъсири маълумоти қаблан истифодашуда ба модели аллакай омӯзондашуда на ҳамеша аз ҷиҳати техникӣ пурра баргардонда мешавад; аммо сабти аслӣ ва маълумоти пайвастшаванда, агар нигоҳ дошта шаванд, то ҳадди имкон ҳазф мегарданд.

7. Ҳуқуқҳои шумо

Бо назардошти қонунҳои татбиқшаванда, шумо метавонед:

  • фаҳмед, ки кадом маълумоти шумо нигоҳ дошта мешавад;
  • маълумоти нодурустро ислоҳ кунед;
  • розигии худро барои коркарди оянда бозпас гиред;
  • ҳазф ё маҳдуд кардани коркардро дархост кунед;
  • дар бораи истифодаи нодуруст ё ҳодисаи амниятӣ хабар диҳед.

Бозпас гирифтани розигӣ ба қонунияти коркарде, ки пеш аз он бо розигии шумо анҷом шудааст, таъсир намерасонад.

8. Амният ва иштироки ноболиғон

Лоиҳа маҳдуд кардани дастрасӣ, калиди сервер, нигоҳдории маҳаллӣ ва ҷудо кардани ном аз вазифаи санҷишро истифода мебарад. Бо вуҷуди ин, ҳеҷ низоми техникӣ амнияти мутлақро кафолат дода наметавонад.

Версияи MVP барои шахсони 18‑сола ва калонтар пешбинӣ шудааст. Сабти овози ноболиғ танҳо бо тартиби алоҳида ва розигии дурусти волидайн ё намояндаи қонунӣ иҷозат дода мешавад.

9. Маълумот дар бораи ҳамин вебсайт

Сайт cookie-и таблиғотӣ ё таҳлили дохилии маркетингӣ надорад. Он тавассути GitHub Pages пешниҳод мешавад; GitHub метавонад журналҳои техникии монанди IP, браузер ва вақти дархостро мувофиқи Сиёсати умумии махфияти GitHub коркард кунад.

10. Тамос ва тағйирот

Барои саволи махфият, бозпас гирифтани розигӣ ё дархости ҳазф дар GitHub-и лоиҳа дархости нав кушоед ва танҳо хоҳиши роҳи тамоси хусусиро нависед. Овоз, номи ҳақиқӣ, рақами телефон, рамзи ихтиёрӣ ё дигар маълумоти ҳассосро дар Issue-и ҷамъиятӣ нагузоред.

Ҳангоми тағйири намудҳои маълумот ё ҳадафи коркард ин сиёсат нав мешавад. Агар тағйирот барои розигии қаблӣ муҳим бошад, барнома бояд пеш аз сабти нав розигии шуморо дубора талаб кунад.
